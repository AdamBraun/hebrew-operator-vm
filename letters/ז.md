# ז — Exported supported projection (focus stays)

Status: synced to the current reference runtime.

## Definition

Unary. Same committed direct-support shape as ן, but without focus advance and with the port exported to `K`.

- **Select:** current focus `(F)`.
- **Bound:** allocate port `p := alloc()`.
- **Graph edges emitted:**
  1. `cont(F, p)`
  2. `supp(p, F)`
- **Other state changes:** set `edge_mode(p) := committed`; set `envelope.data_flow := SNAPSHOT`; mark `p` as a `resolved_port`; export `p` to `K`.
- **Seal:** keep `F` unchanged.

Non-normative note: committedness here is structural rather than policy-gated. The port is treated as a sealed witness by its edge mode and envelope, not by `policy`. The same shared resolved-port helper is reused for the internal `ח` ports.
