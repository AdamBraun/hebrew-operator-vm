# ן — Final nun (immediately resolved continuation)

Status: target behavior for the current reference runtime. Code sync may lag.

## Definition

Unary. Same materialized graph edges as `ז` (cont+carry+supp). The only semantic delta from `ז` is that `ן` advances focus to the successor and does not export that successor to `K`.

- **Select:** current focus `(F)`.
- **Bound:** allocate successor `F^{+} := alloc()`.
- **Graph edges emitted:**
  1. `cont(F, F^{+})`
  2. `carry(F, F^{+})`
  3. `supp(F^{+}, F)`
- **Other state changes:** `ן` adds no extra export to `K`. If a surrounding or default seal exports the current output, this operator adds nothing beyond that default.
- **Seal:** set `F := F^{+}`.
- **Invariant:** `Edges(ן) == Edges(ז)` after renaming `ז`'s exported port `p` to `F^{+}`. The difference is only `F := F^{+}` for `ן` versus `export to K` with `F` unchanged for `ז`.
- **Non-effects:** `ן` does not add extra policies, flags, or relation rewrites beyond the resolved `cont/carry/supp` pattern shared with `ז`.
