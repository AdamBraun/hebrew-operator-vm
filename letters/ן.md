# ן — Final nun (directly supported continuation)

Status: target behavior for the current reference runtime. Code sync may lag.

## Definition

Unary. Same forward continuation and direct support shape as `ז`, but without `carry`. The semantic delta from `ז` is that `ן` advances focus to the successor and does not export that successor to `K`.

- **Select:** current focus `(F)`.
- **Bound:** allocate successor `F^{+} := alloc()`.
- **Graph edges emitted:**
  1. `cont(F, F^{+})`
  2. `supp(F^{+}, F)`
- **Other state changes:** `ן` adds no extra export to `K`. If a surrounding or default seal exports the current output, this operator adds nothing beyond that default.
- **Seal:** set `F := F^{+}`.
- **Invariant:** `ן` keeps the same committed successor shape as `ז`, but omits the `carry(F, F^{+})` edge. The difference is `F := F^{+}` for `ן` versus `export to K` with `F` unchanged for `ז`, plus `ז` retaining carry while `ן` does not.
- **Non-effects:** `ן` does not add extra policies, flags, or relation rewrites beyond the committed `cont/supp` pattern.
