# ק — Bare head with detached adjunct leg

Status: synced to the current reference runtime.

## Definition

- **Select:** current construct/source `X`. On word-entry baseline, use word-entry focus `W₀`.
- **Bound:** allocate bare head `h` and detached leg `ℓ`.
- **Graph edges emitted:**
  1. `head_of(h, X)`
  2. `cont(X, h)`
  3. `carry(X, h)`
  4. `cont(h, ℓ)`
  5. `carry(h, ℓ)`
  6. `sub(h, ℓ)`
- **Other state changes:** export `ℓ` as an adjunct of `h`
- **Seal:** set `F := h`.
- **Non-effects:** current code does **not** add `supp(h, X)` or `supp(ℓ, h)`.

## Interpretation

An unresolved head that also issues a detached, hanging act-line.

## Family

- `ר`: head only, unresolved
- `ד`: head only, resolved
- `ק`: head + detached leg, unresolved
- `ה`: head + detached leg, resolved
