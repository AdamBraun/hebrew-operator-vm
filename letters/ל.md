# ל — Hold and Step Past

Status: synced to the current reference runtime.

See also: [Hold Family Topology](hold-family-topology.md).

## Definition

- **Select:** current focus `(F)`.
- **Bound:** allocate resolved hold `h := alloc()` and exterior successor `o := alloc()`.
- **Graph edges emitted:**
  1. `cont(F, h)`
  2. `carry(F, h)`
  3. `supp(h, F)`
  4. `cont(h, o)`
- **Seal:** set focus to `o`.
- **Non-effects:** do **not** add `carry(h, o)`, `supp(o, h)`, or any boundary/enclosure record.
- **Shape note:** ל is the step-past member of the כ-based hold family: the hold is resolved first, then focus advances beyond it.
