# ח — Adjacency -> interface (two committed ports bridged)

Status: synced to the current reference runtime.

## Definition

- **Select:** `inside` (the current operand / focus) and derive `outside` from the current frame or ambient.
- **Bound:**
  1. create committed resolved port `p_in` for `inside` with `cont(inside, p_in)` and `supp(p_in, inside)`
  2. create committed resolved port `p_out` for `outside` with `cont(outside, p_out)` and `supp(p_out, outside)`
  3. allocate interface object `I`
  4. bridge `p_in` and `p_out` through `I`, so `inside` and `outside` relate only via `I`
- **Seal:** return `I` as the letter output handle.
- **Note:** ח is operationally two ז-style committed ports bridged into a single interface object, but its internal ports emit no local `carry`.

## Signature

- Arity: req 1, opt 0.
- Operand kinds: any.
- Selection precedence: default (see `spec/60-VM.md`).
- Distinctness/reflexive: default (see `registry/letters.yaml`).
