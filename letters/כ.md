# כ — Resolved Hold (kaf = כף)

Status: synced to the current reference runtime.

See also: [Hold Family Topology](hold-family-topology.md).

## Definition

- **Select:** current focus `(F)`.
- **Bound:** allocate resolved hold `h := alloc()`.
- **Graph edges emitted:**
  1. `cont(F, h)`
  2. `supp(h, F)`
- **Seal:** set focus to `h`.
- **Final ך:** same resolved hold, but additionally set `policy(h) := final`.
- **Non-effects:** do **not** allocate any successor beyond `h`, do **not** push any obligation, and do **not** create a boundary or enclosure record.
