# ו — Minimal continuation (carryless spine advance)

Status: synced to the current reference runtime.

## Definition

Unary. `ו` only advances the spine.

- **Select:** current focus (F).
- **Bound:** allocate successor (`F^{+} := alloc()`).
- **Graph edges emitted:**
  1. `cont(F, F^{+})`
- **Seal:** set `F := F^{+}`.
- **Note:** `ו` is the carryless member of the continuation family: `ו = cont`; `נ = cont + carry`; `ן = cont + supp`; `ז = cont + supp`, but focus stays put and exports the supported node.
- **Non-effects:** `ו` does not create `carry`, does not create `supp`, and does not group, partition, or connect two pre-existing operands.

## Milui

Milui of `ו` is compositional, not modal. Base `ו` always keeps the same unary
primitive action: allocate one successor, add one `cont`, and advance focus.

- `וו` = extend, then extend.
- `ויו` = extend, then `י` contributes its ordinary seed/pin behavior, then extend again.
- `ואו` = extend, then `א` contributes its ordinary alias/transport behavior, then extend again.

No milui expansion changes the primitive action of plain `ו`, and no milui
spelling implies that base `ו` performs grouping or hidden connective switching.
