# ם — Close Enclosure

Status: implemented.

See also: [Hold Family Topology](hold-family-topology.md).

## Definition

- **Select:** current focus `F` inside an open `מ` enclosure, or a descendant of that interior.
- **Bound:**

  ```text
  s := alloc()
  add cont(F, s)
  add supp(s, F)
  close the nearest open BoundaryRecord whose inside matches or contains F
  ```

- **Seal:** set `F := s`.

If no open mem enclosure exists, `ם` synthesizes `מ` and then closes it immediately on the
same anchor.

## Signature

- Arity: req 1, opt 0.
- Operand kinds: any.
- Distinctness/reflexive: defaults from [registry/letters.yaml](/Users/adambraun/projects/letters/registry/letters.yaml).

## Notes

- The closed result is a resolved successor of the interior work.
- The sealing step is direct-backed: `cont(F, s)` plus `supp(s, F)`, with no local `carry`.
- Synthetic fallback still creates the minimal open enclosure before sealing it.
- Word-boundary auto-close is silent; `ם` is only needed when the enclosure should seal
  inside the same word.
