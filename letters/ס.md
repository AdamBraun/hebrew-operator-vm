# ס — Nearest unresolved carry closure

Status: synced to the current reference runtime.

## Definition

- **Select:**
  1. walk backward from `F` along `cont`
  2. at each visited node `v`, inspect incoming carries `carry(s, v)` whose source `s` is on the same `cont*` lineage
  3. choose the nearest unresolved source `s`
- **Graph edges emitted:** if such a source `s` exists, add `supp(F, s)`; otherwise none.
- **Seal:** keep `F` unchanged.
- **Non-effects:** current code does **not** harden policy, create a hull handle, or manipulate an obligation stack.
