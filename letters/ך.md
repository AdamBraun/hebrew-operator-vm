# ך — Final Resolved Hold (kaf = כף)

Status: spec synced with `mission-statement.md`. Implementation may differ.

## Definition (from mission-statement)

- **Select:** current focus `(F)`.
- **Bound:**
  1. allocate resolved hold `h := alloc()`
  2. add `cont(F, h)`
  3. add `carry(F, h)`
  4. add `supp(h, F)`
- **Seal:** set focus to `h`.
- **Final effect:** set `policy(h) := final`, sealing the hold against further refinement.
- **Non-effects:** do **not** allocate any successor beyond `h`, do **not** push any obligation, and do **not** create a boundary or enclosure record.

- Arity: req 1, opt 0.

- Distinctness/reflexive: default (see `registry/letters.yaml`).
