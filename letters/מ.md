# מ — Hold and Step Into Enclosure

Status: synced to the current reference runtime.

See also: [Hold Family Topology](hold-family-topology.md).

## Definition

- **Select:** current focus `F`.
- **Bound:**

  ```text
  h := alloc()
  i := alloc()
  add cont(F, h)
  add carry(F, h)
  add supp(h, F)
  add cont(h, i)
  add BoundaryRecord { id: alloc(), inside: i, outside: h, open: true }
  ```

- **Seal:** set `F := i`.

`מ` creates a resolved hold plus an interior continuation. The only graph fact that
makes the successor interior rather than exterior is the `BoundaryRecord`.

## Signature

- Arity: req 1, opt 0.
- Operand kinds: any.
- Distinctness/reflexive: defaults from [registry/letters.yaml](/Users/adambraun/projects/letters/registry/letters.yaml).

## Notes

- No `carry(h, i)`.
- No `supp(i, h)`.
- No obligation-stack push.
- At a word boundary, any still-open mem enclosure closes silently.
